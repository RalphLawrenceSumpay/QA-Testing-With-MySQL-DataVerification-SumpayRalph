# Kara David's Wish Note: QAT Toolkit

## Repository Overview

This QAT toolkit / repository contains three parts:

- **Part A:** This README file, containing the test case for an AI-generated web application.
- **Part B:** The AI prompt used to create the test web application, named `webapp-generation-prompt.txt`.
- **Part C:** The single-file PHP web application generated by AI (`test-webapp.php`).

The original test case source is recorded in `textcase.txt`.
