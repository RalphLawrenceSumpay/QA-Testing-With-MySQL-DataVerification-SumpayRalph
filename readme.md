# Kara David's Wish Note: QAT Toolkit

## Repository Overview

This QAT toolkit / repository contains three parts:

- **Part A:** This README file, containing the test case for an AI-generated web application.
- **Part B:** The AI prompt used to create the test web application, named `webapp-generation-prompt.txt`.
- **Part C:** The single-file PHP web application generated by AI (`test-webapp.php`).

The original test case source is recorded in `textcase.txt`.

## Test Case Documentation

| Field | Details |
|---|---|
| **Test Case ID** | TC-DataEntry-001 |
| **Title** | Data Entry - Valid |
| **Description** | Functional testing of the Data Entry page with backend validation using MySQL queries. |
| **Preconditions** | The Kara David Birthday Wishnote App is installed locally and the MySQL database is pre-populated for comparison. The Data Entry page is accessed in the latest Chrome/Firefox browser. |
| **Test Data** | Five (5) valid entries containing First Name, Last Name, Government Position, and Location, each within its maximum character limit. |
| **Status** | Failed |

| i | Verify that the test data shows in the database (table `main_corrupt_politicians`) using `SELECT * FROM main_corrupt_politicians;`. | All five entries appear, including their Location values. | **Failed.** 5 rows were saved, but the `Location` column is NULL in all 5 rows. |

## Defect Summary

- **Defect:** The `Location` value entered in the form is not saved to the database.
- **Cause:** The INSERT statement omits the `Location` column (intentional flaw in `test-webapp.php`).
- **Evidence:** `SELECT * FROM main_corrupt_politicians;` shows `Location = NULL` for all 5 rows, while FirstName, LastName and GovPosition were saved correctly.
